# Publication record

The owner authorized GitHub upload and GitHub Pages publication on 21 September 2026. This repository publishes the completed moderation experiment discussed immediately before that authorization. The earlier Jev benchmarks and private workflow examples are outside this release.

The original research workspace remains unchanged by Git operations. This separate publication checkout uses the feature branch `research/moderation-publication`, also the source branch for GitHub Pages. There is no main/master push, PR merge, workflow dispatch, or change to the user's home Git file. The new repository has no pre-existing project directives; inherited branch discipline applies. The original no-Git exception continues for the research workspace.

Prediction records retain their historical paths and recorded hashes for auditability. Those paths identify the original machine; they are not required to exist for saved-prediction scoring. Source text, model weights, authentication credentials and raw telemetry requests are excluded. Dataset and upstream model terms remain their own.

`SHA256SUMS.json` is the checksum inventory of the earlier local review bundle, retained as historical evidence. `PUBLIC_SHA256SUMS.json` is the publication file inventory; it excludes itself and Git metadata. The public presentation adds charts and reproduction links without changing recorded predictions or scores.
